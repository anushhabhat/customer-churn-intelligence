# Churn Intelligence Dashboard

An end-to-end churn analysis project built on the IBM Telco Customer Churn dataset.

## What this project covers
- **SQL** — 20+ queries for churn analysis, cohort retention, and high-value customer segmentation
- **Python** — EDA, XGBoost churn prediction model (84% AUC)
- **Power BI** — 3-page executive dashboard with ML-powered risk scoring

## Key Findings
- Month-to-month customers churn at 42% vs 3% for two-year contracts
- Monthly revenue lost to churn: ₹1,39,000
- High-risk active customers flagged for targeted retention campaigns

## Tech Stack
Python · SQL · XGBoost · Power BI

[IBM Telco Customer Churn — Kaggle](https://www.kaggle.com/datasets/blastchar/telco-customer-churn)
